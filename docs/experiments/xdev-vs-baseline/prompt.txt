实现一个 CLI 工具 cronspec：解析并校验 crontab 时间表达式。

**规范以 crontab(5) 为准**，权威文本在这里（先取回来再动手）：
https://raw.githubusercontent.com/cronie-crond/cronie/master/man/crontab.5

要求：

1. `cronspec check "<expr>"` —— 校验一个 5 字段的 crontab 表达式
   - 合法 → 打印 `OK`，退出码 0
   - 非法 → 打印全部问题，退出码 1
2. `cronspec next "<expr>" [n]` —— 从 2026-01-01T00:00:00（本地时区）起，
   打印接下来的 n 个触发时刻（默认 5），格式 `YYYY-MM-DD HH:MM`
3. 必须支持规范里定义的这些写法：`*`、数字、范围 `a-b`、步长 `*/n` 与 `a-b/n`、
   列表 `a,b,c`、月份与星期的三字母英文缩写（大小写不敏感）、
   以及星期的 `7` 与 `0` 都表示星期日
4. 必须支持规范里列出的全部特殊写法（`@reboot` `@yearly` `@annually` `@monthly`
   `@weekly` `@daily` `@hourly`）；`@reboot` 在 `check` 下合法、在 `next` 下报错
5. 必须附一份**校验报告**，证明工具对规范里定义的**每一种**非法情形都能检出
6. 必须附一个**可复现的验收脚本**，一条命令跑完全部判据

## 约束

- 只用标准库，不引入第三方依赖
- Python 3，单文件 `cronspec.py`，可执行
- 工作目录就是当前目录，不要 cd 到别处
