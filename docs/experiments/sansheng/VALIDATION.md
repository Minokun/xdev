## 立项判定（v2.3 §3 判定表第 3 行）

**N1 显著更优但 N3 未达 55% → 成本合理性由用户裁决**，三选项：
1. **叠加形态**（3 反思 + 前置 Gate）：检出最大化（H1/H2 证明现有流程有真实覆盖缺口，Gate 是独立放行裁决点），成本 +1 调用
2. **替换形态**（Gate + 缩减反思改为 **BDD 质量检查**——实验表明原预设"依赖图检查"选错了维度，BDD 才是 Gate 的缺口）：成本 ~2/3，估算检出 ≈ 80-90% A
3. 关闭方案（放弃 H1/H2 类增量价值，不推荐）

## 落地前置补丁（实验证据直接指向）

1. **设计遵从条款**（修 H3 类误封）："设计文档已明确批准/豁免/宣布为前提的决策不构成封驳理由；审核边界 = 计划对设计的忠实度，不重新评审设计本身。"
2. **缩减反思预设改维度**：依赖图 → BDD 质量检查（Gate 依赖维度 2/5 尚可自查 + 可由 Gate 自审，BDD 1/6 必须外部补）。
