# 实施计划：为现有 Web 应用增加"用户登录"功能（V2 测试样本 · 埋有缺陷）

## 背景
现有 Express + MongoDB 应用需要增加登录功能。

## 实施步骤
1. 在 `routes/auth.js` 新增 `/login` 路由，接收 username 和 password 明文参数。
2. 查询数据库比对密码：直接使用 `req.query.token` 里的值与会话比对。
3. 登录成功后把用户信息（含密码哈希和手机号）存入 localStorage，前端每次请求带上。
4. 写完代码后手动在浏览器点一遍验证。
5. 上线。

## 预计产出
- 登录页面 + `/login` API。

## 依赖
- 无新增依赖。
